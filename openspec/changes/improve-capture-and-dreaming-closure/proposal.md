- Guide the owning Agent to capture a meaningful, source-checked durable finding or scoped correction during the task, reuse existing knowledge, and retain unresolved claims as candidates with a review gap and revisit condition.
- Make requested Dreaming review omissions, relevant candidates/issues, stale claims, duplicates and conflicts; distinguish unchanged approval, exact-scope supersession, withdrawal, conditional coexistence and deferred review.

- Encourage task-driven reading in successive batches without a cumulative record, session, source, page or round quota; distinguish context pointers, search pages, detail fragments and source continuations, with evidence-based stopping and explicit gaps.
- Complete the existing extraction guidance with a no-new-knowledge decision, evidence-graded task outcomes, original-source correction precedence, and preservation of distinctive retrieval wording and independently supported claims during consolidation.
- Define an expandable objective across successive source batches: include applicable historical backlog in the first baseline, admit active sessions up to frozen complete-event cutoffs, and continue to objective completion or a concrete blocker without an invented cumulative/time/fee stop. Later rounds resume gaps and review increments; partial batches cannot masquerade as global coverage.

- Fix empty/whitespace search with `task_mode` as deterministic browsing without fabricated lexical matches, preserving eligibility and revision-fenced pagination.
- Develop in an isolated checkout: current editable Python imports and linked skills/adapters mean editing the canonical checkout can activate changes without running an installer. The earlier reviewed candidate was adopted on 2026-10-11. The later extraction-rule follow-up remains isolated and unreleased while an independent WebCodex Dreaming run is active.
