## Deliberate limits and unrun gates

The complete [operations/capability matrix](operations.md) is the contract for supported invocation and limits. In particular:

- Bounded parser windows are not unlimited history support: 8 MiB consumed prefix, 1,024 event identities, 64 KiB line allocation and a bounded Run working set. Unsupported native schemas or Pi ancestry outside the window remain gaps. Verification costs can require smaller authorized source exports or a larger approved budget.
- The native executor identity is operator-bound and explicitly unverified. Endpoint denial is not same-UID filesystem isolation or qualification of a native harness's other tools. Default serve mode is advisory.
- The core has no model/provider caller. It records channel/budget intent, but a real external harness must independently enforce token/provider cost and whole-tool-pool restrictions.
- Startup views are opt-in; revocation is enforced at the next actual read/lifecycle refresh, not by erasing existing model context. Machine checks cannot prove semantic entailment or replace evidence review.
- No paid native Codex/Pi/Claude Dreamer session, real memory pilot, real consuming-model session or navigation/summary/Dreamer semantic comparison was run. No installation or activation was performed.
