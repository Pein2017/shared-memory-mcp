## Why

Startup currently ranks empty queries by oldest capture time, while Latin character bigrams admit unrelated search results. Durable lessons are mixed with handoff state, and full audit envelopes compete with useful recall text. The user approved implementation of the audited four-stage improvement, low-risk source-checked publication, and explicit cross-project engineering reuse on 2026-10-05.

## What Changes

- Make empty-query startup a stable navigation view; task queries return relevant cards and explicit source/read paths, without a mandatory search gate or dynamic project pulse.
- Replace weak character-substring admission with field-aware lexical ranking, curated aliases, explainable matches, bounded pagination, and optional task-domain preference.
- Keep version-1 canonical Markdown readable. Add a small integrity-bound curation journal for optional summaries, conditions, topic/source roles, sharing and retirement; it is retrieval metadata, not a new evidence owner.
- Add one-call source-reviewed capture and reviewed curation/retirement. Preserve candidate workflows, immutable accepted bodies, idempotency, withdrawal and exact-scope correction. Retirement does not refute evidence; differing research conditions do not imply supersession.
- Permit only explicitly marked project-scoped engineering records through a directional project allowlist. Imported records remain read-only and retain their original project attribution.
- Preserve the completed, separately owned Pi stable-prefix changes. Keep tool catalog order and descriptions stable, annotate effects accurately, and retain interoperable bounded structured/text MCP responses. Support actual WebCodex caller context through a local CLI bridge without impersonating Codex.
- Migrate existing handoff recall by source-checked curation and durable extraction only where needed; preserve all original records, existing handoff capability, native memories and evidence owners.

**Compatibility change:** empty-query `context` becomes routing-only and `search` becomes a card projection. Existing seven operation names remain; full record reads remain available. Older already-running processes keep their pre-upgrade behavior until reconnected and are not forcibly restarted.
